🛒 E-Commerce Website

This is a task from SPCL Infotech Services Pvt.Ltd. to design and develop a dynamic and responsive online store homepage. The website has features categorized into product listings displayed as cards and included different types products with added add to cart functionality.

📌 Overview

This is a responsive e-commerce website built using HTML, CSS, and JavaScript. It allows users to browse products, view details, add items to the cart, and proceed to checkout.
The project focuses on front-end functionality and user experience, making it ideal for learning and showcasing web development skills.

🚀 Features

🏠 Home page with featured products

🛍️ Product listing page

🛒 Add to cart functionality

➕ Increase/decrease product quantity

💾 Cart data stored using localStorage

💳 Checkout page design

📱 Fully responsive design

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)
